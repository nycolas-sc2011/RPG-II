LISTA DE EXERCÍCIOS - Python no mundo do RPG
=============================================

Os três exercícios formam UM jogo, construído aos poucos:

  ex1/  Batalha por turnos       laços, decisão, funções, parâmetros
  ex2/  Loja do herói            + módulos e arquivos JSON
  ex3/  Arena com ranking        + banco de dados (SQLite)

Em cada pasta:
  - complete as funções marcadas com TODO (apague o "raise NotImplementedError");
  - rode o arquivo testes_exN.py para conferir: cada teste mostra OK ou ERRO;
  - depois rode o programa principal e jogue.

Programas principais
  ex1:  batalha.py      ex2:  main.py      ex3:  arena.py

ANTES DO EXERCÍCIO 3, copie para a pasta ex3:
  - o seu batalha.py  (da pasta ex1)
  - o seu arquivos.py (da pasta ex2)
  - o seu heroi.json  (criado na pasta ex2 quando você sai da loja com a opção 0)

Todos os arquivos de um exercício precisam ficar na MESMA pasta.
Editor recomendado: Thonny (thonny.org). Não é preciso instalar mais nada.
